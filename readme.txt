Juarez Detailing QR files

Juarez_Detailing_MultiLink_QR.png is a real QR code that encodes the supplied phone, service areas, and social/payment URLs as text. Scan it with a phone camera to display the text and links.

Important limitation: this is not yet a single tap-friendly landing page. For that, the HTML page must be hosted at a public HTTPS URL, and a new QR code can then point directly to that URL.
